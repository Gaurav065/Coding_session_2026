# Azure Data Factory (ADF) Deep Dive & Interview Prep 🚀

## Core Focus Areas
1. **Core Architecture & Components**:
   - Pipelines, Activities (Control flow vs. Data transformation), Datasets, Linked Services.
2. **Integration Runtimes (IR)**:
   - Azure IR, Self-Hosted IR (SHIR) - High Availability / Scaling / Networking, Azure-SSIS IR.
3. **Data Movement & Transformation**:
   - Copy Activity (Performance tuning: DIUs, parallel copies, staging).
   - Mapping Data Flows & Wrangling Data Flows.
   - Lookup, Get Metadata, ForEach, Until, If Condition, Execute Pipeline.
4. **Parameters, Variables, and Expressions**:
   - Dynamic content expressions, Pipeline/Dataset parameters, Global parameters.
5. **Triggers & Orchestration**:
   - Schedule, Tumbling Window (dependencies, backfill, self-dependency), Storage Event, Custom Event.
6. **Security & DevOps / Monitoring**:
   - Managed Identity, Azure Key Vault integration, Private Endpoints.
   - CI/CD with Git integration & ARM templates.
   - Alerts, Diagnostic settings, Log Analytics.
